# 🌐 BÀI 2 – HTTP SERVER ĐẦU TIÊN VỚI NODE.JS

## 1. Giới thiệu
Bài thực hành xây dựng một HTTP Server bằng Node.js thuần. Máy chủ tiếp nhận yêu cầu từ trình duyệt và trả về trang HTML hiển thị nội dung lời chào.

## 2. Công nghệ sử dụng
- Node.js
- JavaScript
- HTML
- HTTP Module
- Visual Studio Code

## 3. Chức năng
- Khởi tạo HTTP Server bằng `http.createServer()`.
- Lắng nghe kết nối tại cổng 3000.
- Xử lý yêu cầu HTTP từ trình duyệt.
- Trả về nội dung HTML.
- Hiển thị trang web thông qua localhost.

## 4. Cấu trúc thư mục

```text
BAI2/
└── server.js
```

## 5. Hướng dẫn chạy chương trình

**Bước 1:** Mở thư mục BAI2 bằng Visual Studio Code.

**Bước 2:** Mở Terminal và chạy lệnh:

```bash
node server.js
```

**Bước 3:** Mở trình duyệt và truy cập:

```text
http://localhost:3000
```

## 6. Kết quả
- HTTP Server khởi chạy thành công.
- Máy chủ hoạt động tại cổng 3000.
- Trình duyệt hiển thị trang HTML.
- Người dùng có thể truy cập website thông qua localhost.

## 7. Kết luận
Qua bài thực hành, chúng ta đã tìm hiểu cách tạo HTTP Server bằng Node.js thuần, xử lý yêu cầu HTTP và trả về nội dung HTML cho trình duyệt.
